# ACT 模型 TPU 推理 — 测试记录

## 测试环境

| 项目 | 值 |
|------|-----|
| 硬件 | LicheeRV Nano SG2002, C906 RISC-V @ 1GHz, 256MB DRAM |
| 操作系统 | StarryOS (commit `c550b7b85`) |
| TPU | CV181x BF16 @ ~1 TOPS |
| 模型 | `act_model_det_cv181x_bf16.cvimodel` (96MB BF16) |
| 推理程序 | `act_infer_batch` (C, 静态链接 RISC-V ELF) |
| 测试日期 | 2026-05-28 |

## 测试设计

**100 个测试用例**，覆盖 7 种输入分布。所有输入使用固定随机种子 `np.random.RandomState(42)` 生成，确保可复现。

| 用例范围 | 数量 | 输入分布 | 说明 |
|---------|------|---------|------|
| 0-4 | 5 | images=zeros, state=zeros | 全零基线 |
| 5-9 | 5 | images=zeros, state=[0.5, -0.3] | 零图+固定状态 |
| 10-19 | 10 | images=U(-1,1), state=[0.5,-0.3] | 均匀随机图像 |
| 20-29 | 10 | images=U(-1,1), state=N(0,0.25) | 均匀随机+小状态 |
| 30-49 | 20 | images=N(0,0.25), state=N(0,0.25) | 正态随机图像 |
| 50-69 | 20 | images=N(0,0.01), state=N(0,9) | 小图像+极端状态 |
| 70-84 | 15 | images=mixed(0.5,0.09), state=N(0,4) | 混合分布 |
| 85-99 | 15 | images=structured(sin), state=U(-2,2) | 结构化图像 |

每个用例输出 16 个值（8 个时间步 × 2 个动作维度），共 **1600 个对比点**。

## 复现脚本

```bash
# 1. 编译内核
cargo xtask starry quick-start licheerv-nano-sg2002 build

# 2. 生成 FIT image
mkimage -f boot.its boot.sd

# 3. 拼装 SD 卡镜像（详见 act-tpu-reproduce.md）

# 4. 运行 PyTorch 基线
python3 -c "
import torch, numpy as np
# ... load model, run 100 cases with seed=42
np.savez('pt_ref.npz', outputs=results)
"

# 5. 板上运行
/tpu/act_infer_batch /tpu/act_model.cvimodel /tpu/test_inputs /tpu/test_outputs

# 6. 对比精度
python3 compare.py board_output.txt pt_ref.npz
```
